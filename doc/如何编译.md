# AFSIM 编译指南

## 一、编译步骤

1. **CMake 配置**：使用 CMake 配置并生成工程。
2. **全量编译**：编译 `ALL_BUILD` 目标，生成文件在 `Release` 目录下。

   ```powershell
   cmake --build <build目录> --config Release --target ALL_BUILD
   ```

3. **INSTALL 编译**：完成后再编译 `INSTALL` 目标，生成文件在 `wsf_install` 目录下；然后将 `wsf_install\bin` 目录下的所有文件复制到 `Release` 目录并覆盖。

   ```powershell
   cmake --build <build目录> --config Release --target INSTALL
   Copy-Item <build目录>\wsf_install\bin\* <build目录>\Release\ -Force
   ```

4. **运行配置**：将 `wizard` 设为启动项，并将所需的 `resources`、`demos`、`documentation` 拷贝到 `Build` 目录下。

## 二、编译后程序

### 🎯 三大核心应用（用户最常用）

| 程序 | 功能 | 直白理解 |
|---|---|---|
| **wizard.exe** | 图形化 IDE/想定编辑器 | AFSIM 的"开发环境"，用来写场景脚本、编辑平台、配置传感器/武器、点击运行仿真 |
| **warlock.exe** | 实时/超实时仿真引擎 | 核心仿真驱动引擎，支持人在回路交互推演，可实时干预、下发指令 |
| **mystic.exe** | 回放与批量分析工具 | 读取仿真输出的 `.aer` 文件，做态势回放、曲线绘制、蒙特卡洛统计、交战链分析 |

### ⚔️ 专项仿真工具

| 程序 | 功能 | 直白理解 |
|---|---|---|
| **engage.exe** | 1v1 交战仿真 | 专注于单对单武器交战分析（如导弹 vs 目标） |
| **mission.exe** | 超实时任务级仿真 | 跑大规模任务级场景，速度可达实时的数百倍 |
| **sensor_plot.exe** | 传感器探测可视化 | 绘制传感器覆盖范围、探测概率曲线（`.plt` 文件） |
| **weapon_tools.exe** | 武器分析工具 | 武器性能评估、弹道计算 |
| **scene_generator.exe** | 场景生成器 | 自动生成大规模战场场景/平台部署 |

### 📊 数据分析与后处理工具

| 程序 | 功能 |
|---|---|
| **post_processor.exe** | 后处理器：读取仿真输出数据，做筛选、统计、格式化报告 |
| **evt_reader.exe** | 事件阅读器：读取 `.evt` 事件日志文件，以表格形式查看、过滤、导出事件 |
| **crd_importer_exec.exe** | CRD 数据导入器：将外部数据（如威胁数据库）导入 AFSIM 格式 |
| **mystic.exe** | 批量分析器：蒙特卡洛统计，输出 `.aer` 分析报告 |

### 🛠️ 辅助工具

| 程序 | 功能 |
|---|---|
| **mover_creator.exe** | 运动体创建器：生成平台轨迹/航迹数据 |
| **pack_to_cpp.exe** | 打包工具：将资源文件打包为 C++ 代码嵌入编译 |

## 三、典型工作流程

```
1. 编辑场景
   wizard.exe → 编写 .txt 场景文件（SDL 脚本）

2. 运行仿真
   warlock.exe → 实时推演（人在回路）
   mission.exe → 超实时批量跑场景

3. 查看结果
   mystic.exe    → 态势回放 + 统计分析
   evt_reader.exe → 查事件日志
   post_processor.exe → 生成报告
   sensor_plot.exe → 画探测曲线
```
